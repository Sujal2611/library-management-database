# Library Management System | MySQL Database Project

## Project Overview
Designed and developed a relational database management system using MySQL to manage library operations, including books, members, authors, loans and fines.

## Project Objectives
- Organize library information through a structured relational database.
- Manage book availability and member records.
- Track book borrowing, returns and outstanding fines.
- Analyze borrowing patterns and popular books.
- Maintain data consistency using database constraints and relationships.

## Tools & Technologies
- MySQL
- SQL
- Relational Database Design
- MySQL Workbench

## Database Architecture

The project consists of six interconnected tables:

1. Books
2. Members
3. Authors
4. BookAuthors
5. Loans
6. Fines
